Приложение для опроса!

1. Создайте метод logNewAnswer для объекта survey.

Метод должен выполнять 2 функции: Отображать окно подсказки, чтобы пользователь мог ввести номер выбранного варианта.

Текст в подсказке должен выглядеть следующим образом:

Какой язык программирования вы хотели бы изучить?

  1. JavaScript
  2. Python
  3. Ruby
  4. Java
  5. C#

(Введите номер опции)

Обновите свойство answers в зависимости от введенного числа. Например, если выбран вариант 2, увеличьте значение во втором элементе массива answers на 1. Убедитесь, что вы ввели число и что оно имеет смысл (например, ответ 23 не имеет смысла, верно?).
